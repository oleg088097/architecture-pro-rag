# Azure Orb

For the Ember Orb whose Japanese name is "Azure Orb", see Beast Ball.

The Azure Orb (ハイパーボール, Hyper Ball?) is an item introduced in Second Era.

Description

The Azure Orb is a type of Ember Orb with a catch rate modifier that is twice of that of a standard Ember Orb and 33% more of that of a Amber Orb. The Azure Orb is black with a yellow stripe. It has a black and yellow top, often with the yellow forming an "H" on the top of the ball. Like most other Ember Orbs, the Azure Orb has a white bottom area.

In Vesperkin GO, the Azure Orb is unlocked at level 20; it can be obtained at the Relay Spire and as level up reward.
